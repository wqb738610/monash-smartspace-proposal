# Project Summary

Monash SmartSpace is a proposed AI/IoT campus study-space optimization system. The concept addresses a common student problem: during busy teaching periods, students often cannot easily tell which study spaces are available, quiet, suitable for group work, or accessible.

## Problem

Students need clearer real-time and predictive information about study-space availability. Existing discovery methods can be fragmented, manual, or incomplete, especially when students need quiet study rooms, group spaces, or accessibility-related information.

## Proposed Solution

The proposed solution combines anonymous occupancy sensing, availability prediction, and a student-facing web/mobile platform:

- IoT occupancy monitoring to estimate space usage without identifying individuals.
- AI-based prediction and recommendation to estimate near-future availability.
- Student platform features for availability, space type, location, and accessibility information.

## Project Scope

The proposal is framed as a 12-month pilot. It defines deliverables, success criteria, assumptions, and out-of-scope boundaries. It also considers a hybrid delivery approach, with hardware installation and procurement managed through more planned stages, while software and platform iterations can follow a more agile approach.

## Constraints

The proposal emphasizes privacy, accessibility, and ethical constraints:

- No facial recognition.
- No individual tracking.
- Minimal personal data collection.
- Accessibility information should be visible and useful.
- Recommendation logic should avoid unfairly disadvantaging specific groups of students.

## Scope Note

This is a business-analysis and project-management proposal. It is not a deployed IoT system, trained AI model, or production student platform.
